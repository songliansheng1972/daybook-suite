# DAYBOOK 样本卷·发布必备三件

供下载者即下即跑。每卷 5 条假条目，体例与生产卷一致。

## 用法

样本卷默认路径在 `daybook.conf` 已配置，直接使用即可。

```ini
[卷]
协作=sample/协作卷.txt
辞海=sample/辞海卷.txt
大宗师=sample/大宗师卷.txt
```

然后：

```bash
python3 daybook.py index
cat 开发卷/volumes.md
```

## 体例

每条：
- 头：`[YYYY-MM-DD HH:MM]`
- 标签：`[类] [标题]`
- 正文：自由文本

5 类 × 3 卷 = 15 条样本，覆盖：架构/审方/方向/实验/范式（协作卷）；纲领/验证/设计/接入/图说（辞海卷）；凡例/方法/判据/校对/材料（大宗师卷）。

## 真实数据 vs 样本

样本卷是**假条目**——内容是合成的，便于他人理解体例。
生产数据归各项目本地，不在发行版内。
