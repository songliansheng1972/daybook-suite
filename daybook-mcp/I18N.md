# DAYBOOK I18N · 标识符英译对照表（canonical naming map）
<!-- English canonical names for identifiers, fields and generated artifacts.
     Chinese names are kept as *legacy aliases*: old conf files, old indexes and
     old query terms keep working. 中文名保留为「兼容别名」：旧 conf／旧索引／旧查询口径照常可用。 -->

方案（老宋 2026-10-16 掌印）：**英文为准 ＋ 中文兼容别名**（three decisions:
English-canonical + Chinese alias ／ scope = src＋3 packages＋sample confs＋docs ／
generated artifact names also English-ified）。
别名归一只有**一处**入口：`load_conf()`（daybook 侧与 multidx 侧各一）。

## 6 · 四库三序（views）——★ 未擅译·候议

`子`／`史`／`集` 为四库目录学的**文化术语**（子·按类／史·按年月／集·按作者）。
英文文档暂写作 *by class / by month / by author*，但**未定为标识符**——
按「把握不准先空着·候议」暂**保持中文**，英文别名待老宋裁后再接。
CLI 仍为 `--order 子|史|集`（值不动），仅参数名英文化。

## 7 · 注释

全仓注释一律**中英对照**（先中文，后英文，同一行或紧邻行；风格保持原文件体例：
`#` ／ `/* */` ／ `C` ／ `REM`）。
