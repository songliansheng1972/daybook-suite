# daybook ORCH · 司南

**不造调度器，只做确定性查表。** 把 daybook 的 append-only 卷，变成多智能体的操作系统——  
谁该动、动到哪一步，**由表定，不由猜**。

> 名号「司南」：《韩非子·有度》「先王立司南以端朝夕」——以器定方向，**不因问者而异**：  
> 同一条，任何时刻、任何人来问，都得**同一个下一手**。

## 卖点

- **确定性** —— 编排器不贡献智能，只贡献方向：**定于查表，不定于推理**。
- **零依赖** —— 只 Python 3 标准库；不新存储、不新协议、不新依赖。
- **两张表人可读可改** —— 类 → 角色 → 人，规则写在纯文本里，**不藏在码里**。
- **不自审** —— `@non-author` 保证裁决者不是作者本人。
- **只增不改** —— 身份 / 任务 / 消息 / 心跳皆落 append-only 卷；看板、收件箱皆派生件，可删可重建。

## 十二动词 · 六原语

- **verbs（12）**：`join` `leave` `who` `open` `claim` `submit` `review` `pull` `board` `alarm` `digest` `selftest`
- **原语（6）**：身份 `agent_registry` · 任务 `task_volume` · 锁 `agent_lock` · 在场 `agent_heartbeat` · 消息 `agent_message` · 引用 `cross_ref`（＋ 路由 `orchestrator`）

## 分发接上目录（v3.1）

账本侧生成**部(卷)→类→属(条目)** 多级目录后，分发不再只是「有新条」，而是「**有新条，且已挂进层级、带提要**」：

```bash
python3 orchestrator.py digest --vol 协作 --limit 5      # 变动摘要（部▸类▸属 ＋ 互见引用）
python3 orchestrator.py digest --cls 核 --push 皮特      # 按类过滤·经 agent_message 推送
```

摘要每条附**互见引用** `↪[卷#L行-SHA8]`（可校验）。缺多级目录件时**按在册卷原文兜底**（自持可跑）；`--push` 收件人不在线**不阻断**（摘要落编排卷）。

> **本轮（未发布）补齐**
> - `--limit 0` = 全部（显式）；正数 = 最近 N 条；**负数非法**（rc=2），不再出现「`-1` 少一条」。
> - 卷表为空 → `src=no-volumes` 且输出/stderr 双告警；卷读失败、互见引用失败都显式标注，**不再把失败伪装成「没有」**。
> - `alarm` 只按结构字段判（心跳时间戳+阈值、注册表成员、状态机位置）；幽灵负责人算硬警。
>   **退出码拆分**：0 干净｜1 有硬警｜2 参数/文件错｜**3 体检执行异常**（读卷/解析失败）。

## 性能（本轮实测）

同一批数据，修前/修后各跑一遍（脚本：`python3 orch_perf_bench.py`；HEAD `d9c4225`，起跑 `2026-11-14 01:05:29`）：

| 场景 | 数据 | 修前 | 修后 |
|---|---|---|---|
| `digest`（20 行） | 1 卷 / 24 条 / 22,800 B | 卷读 21 次 / 478,800 B / 6.20 ms | **卷读 1 次 / 22,800 B / 0.75 ms** |
| `dead_agents` | 200 agent × 5 心跳 / 46,000 B | 卷读 201 次 / 9,246,000 B / 1495.19 ms | **卷读 1 次 / 46,000 B / 10.00 ms** |
| `digest` 百万行 | 1 卷 / 1,000,000 条 / 73,888,900 B | 卷读 21 次 / 1,551,666,900 B / 9493.11 ms | **卷读 1 次 / 73,888,900 B / 6704.80 ms** |

百万行口径说明：修前互见是 **O(命中条数 × 卷字节)**，修后是 **O(卷字节) 一次 + 每条 O(块长)**；
`dead_agents` 修前 **O(agent 数 × 卷字节)**，修后 **O(卷字节)** 单遍。
上表时间受本机页缓存影响（重复读同一文件几乎不落盘），**盘读字节才是硬指标**：百万行 1.55 GB → 73.9 MB（21×）。
百万行剩余耗时来自**兜底直扫 + 全量排序**（修前修后同样存在，非本次回归）；有 `multilevel` 目录件时走目录，不直扫原卷。
复现：`python3 orch_perf_bench.py --scale 1000000 --body 20 --skip-dead`。

## 怎么跑

```bash
cd daybook-orch
python3 orchestrator.py selftest      # 端到端自检（含 digest 2 项）
python3 orchestrator.py join 汤姆
python3 orchestrator.py open "实现 X" --by 汤姆
python3 orchestrator.py pull 皮特      # 取件（查表算下一手）
python3 orchestrator.py board         # 看板
```

`--root DIR` 指定卷根；七卷路径读 `<root>/daybook.conf` 的 `[volumes]` 段（不写用默认文件名，`--root` 一处生效）。`--rule / --roles` 换路由表 / 角色表。

## 边界（诚实）

- 路由**只对已知类**确定；未命中落「广播」，**不猜**。
- `flock` 是**进程级**互斥；跨主机须靠共享文件系统或上层协调。
- 与消息 socket 推送是**可接**关系，未强绑。
