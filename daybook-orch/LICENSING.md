# LICENSING · daybook 三件之授权分层

本仓（及 daybook-suite 三包）**不采用单一许可**——按**件**分层，理由见下。

## 一、分层

| 层        | 件                                                                                                                                       | 许可                                |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------- |
| 基座（账）    | daybook.py・daybook_append.py・safeio.py・daybook_record.py・daybook_session_hook.py・daybook_hook.py・daybook.{sh,c,bas,f,conf}・sentinel*.sh | **MIT**                           |
| 共享原语层    | agent_registry.py・cross_ref.py                                                                                                          | **MIT**                           |
| 璇玑（MCP）  | mcp\_{server,tools,resources,prompts,subscribe,transport}.py                                                                            | **MIT**                           |
| 司南（ORCH） | orchestrator.py・agent_lock.py・agent_heartbeat.py・agent_message.py・task_volume.py・orchestration\_{routing,roles}.conf                    | **AGPL-3.0-or-later**，或**另购商业许可** |

⇒ **起居注（账）与璇玑（MCP）＝ 全开源（MIT）**；**司南（ORCH）＝ 双许可**。

## 二、为什么按「件」不按「包」

三包是**同一批件的不同装配**：`safeio.py`／`daybook_append.py` 三包皆有，  
`agent_registry.py`／`cross_ref.py` 两卫星皆有。**同一件不能挂两种许可**——  
故若按包切，共享件会把 AGPL 漏进璇玑包，把「全开源」染掉。

## 三、司南之双许可（AGPL 或 商业）

- **社区路**：按 **AGPL-3.0-or-later** 使用——**含商用**：企业内部自用（含内部网络供员工用）**免费且合法**；**网络条款**：若把司南作为网络服务**对外**提供，须向用户提供对应源码。
- **商业路**：**不愿履行 AGPL 义务者**，可购买**商业许可**（免除 copyleft 义务）。联系：手艺人老宋 <songliansheng@vip.sina.com>。
- **一句话**：**想闭源嵌入 / 想对外 SaaS 而不开源 / 要官方支持 ⇒ 买商业许可。**  
  ★**不是**「商用就必买」——**内部商用自用本就免费**。

## 四、账之形 与 器之码：分层

- **账之形**（卷之格式·见 `volume_format_spec.md`）：**授权宽**——任何人可读、可写、可在其上建任何东西；只不许改形。
- **器之码**（本仓代码）：**按上表分层**。
- ⇒ 二者层次不同，**勿混**：「账可自由用」不等于「代码可自由用」。

> **一句**：**别人可以拿走我们的「码」，拿不走我们的「名」。**

⚠️ **两条纪律**：

- **不写「最终解释权归本司」**——该语在中国法下（《合同违法行为监督处理办法》第十一条）于格式条款中**一般认定无效**，是**假主权**。要的是可行使的**真主权**。
